# Заезд в Одинцово — Remake / Visual Overhaul

Обновлённая версия исходной игры на Three.js. Основной акцент ремейка — более близкая и читаемая камера за машиной, чистая картинка без агрессивного bloom и цветных ореолов, более детальные процедурные поверхности и аккуратный интерфейс.

## Запуск
Откройте `index.html` через GitHub Pages или локальный сервер (`python3 -m http.server`). Для Three.js нужен интернет: библиотека подключается с CDN.

## Что переработано
- Убрана агрессивная bloom-подсветка и цветное смещение по краям кадра; постобработка теперь сдержанная, без зерна и светящихся ореолов.
- Камера в обычном режиме подъехала к машине, стала ниже и смотрит ближе к дороге; вертикальный экран больше не раздувает поле зрения до чрезмерно широкого.
- Улучшены фильтрация и детализация процедурных текстур земли и асфальта: выше разрешение, мягче микрошум, лучше mipmap/anisotropic filtering.
- Улучшено сглаживание, увеличен запас разрешения теней и настроена более ровная тональная обработка.
- Переработаны HUD, меню, кнопки управления, гараж и всплывающие сообщения: меньше неона, контрастнее типографика, спокойнее материалы интерфейса.
- Ослаблены лишние additive-эффекты у фар, фонарей, следов и частиц.

## Управление
ПК: ← → / A D — руль, S — тормоз, Shift — нитро, C — смена камеры, G — дробовик, ЛКМ / пробел — выстрел, R — перезарядка.
Телефон: кнопки ◀ ▶, тормоз и нитро; кнопка «ВИД» меняет камеру.
